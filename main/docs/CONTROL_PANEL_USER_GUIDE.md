# 上位机详细使用说明

> 版本口径：最终版参数、功能边界与验收结论统一以 [v1.0.0发布说明](../../docs/FINAL_RELEASE.md) 为准。本文带日期的运行数字是对应历史实验记录，不代表最终版重新测得的结果。

更新日期：2026-11-03。适用于当前默认的加速度计/陀螺仪误差传播与 GNSS 校正版本。界面复选框中显示勾号表示开启，空框表示关闭；修改程序后需关闭旧窗口并重新启动上位机。

> 当前默认已升级为加速度计/陀螺仪误差传播与GNSS校正，旧独立PVA误差及80%/20%拆分仅保留历史兼容；以 [GNSS/INS模型说明](../../docs/gnss_ins_model.md) 为准。

本说明面向在 Windows 桌面上配置并生成机载 SAR 航迹的使用者。上位机输出一段高频运动真值及对应的 100 Hz 导航位姿估计，供后续 SAR 仿真选择和裁剪；它不直接控制实机。

## 1. 启动与界面

也可直接双击 `main/UAVMotionSim.exe`。该EXE是项目内的Windows图形启动入口，调用同一套上位机和仿真环境，无须输入命令。请保留完整项目及`.venv`，不要单独移动EXE；新电脑仍须先按项目说明安装环境。它不包含MATLAB或外部飞控平台。重新生成入口可在项目根目录运行 `scripts/build_control_panel_exe.ps1`，无需增加Python依赖。

1. 首次部署时，在项目根目录按 [项目说明](../../README.md) 安装环境。若双击入口后提示找不到项目环境，先执行 `scripts/setup.ps1`。
2. 双击 `main/open_control_panel.cmd`。它打开图形上位机，启动后默认加载 `main/motion_config.yaml`。窗口上方显示当前配置来源。
3. 窗口顶部有“加载配置”“另存配置”“检查参数”“运行仿真”“完整验收”“停止当前任务”和“刷新硬件”。主体分为“参数配置”“运行监控”“结果查看”三个页签。

`main/run.cmd` 是另一条入口：它直接运行 `main/config.yaml` 的固定时长完整验收，不读取上位机当前编辑的参数。要按界面参数运行，请使用上位机内的按钮。

## 2. 从默认参数生成一段航迹

1. 打开“参数配置 → 飞行与采样”。默认“时长计算方式”为 `route_length`，“目标有效航线长度”为 **1000 m**，“名义速度”为 **10 m/s**，“额外飞行裕量”为 **10 s**。
2. 查看页面底部的“参数有效”提示。按 `总时长 = 目标长度 ÷ 名义速度 + 裕量`，默认输出时长为 **110 s**；程序会根据共同采样网格向上对齐。默认积分、SAR 输出和导航频率分别为 3200、800、100 Hz，对应 110 s 输出约 352001、88001、11001 个含端点采样。预稳定时长另由“预稳定时长”设置。
3. 如需改变轨迹或导航质量，按下面各节调整参数，然后点击“检查参数”。“参数校验通过”仅说明字段和组合约束合法，不代表实际仿真已通过。
4. 在“执行与资源”选择仿真航次数 `1` 或 `2`，点击“运行仿真”。窗口自动切换到“运行监控”，显示日志和当前任务状态。默认 1000 m 双航次及高频输出可能耗时较久并占用较多磁盘空间；实际资源计划和耗时以本次输出为准。
5. 完成后窗口自动加载结果。到“结果查看”检查三维航迹、逐帧导航位姿、图表和离线报告。重点查看报告中的“有效航段”及可裁剪时间窗，而不是仅凭输入长度认定实际轨迹达到目标。

“运行监控”的进度条显示阶段加权进度。“运行仿真”的 0–80% 根据各航次实际完成的积分步数汇总，随后显示检查、保存、绘图和生成报告。完整验收的 0–40% 为双航次积分，40–60% 为数据保存、测试与 OU 统计，60–90% 为三种频率的数值收敛（按积分步数加权），最后显示绘图、MATLAB 检查和报告生成；全部通过后到 100%。百分比不是剩余时间预测，测试、保存和 MATLAB 阶段可能停留较久。停止、失败或部分完成会显示相应状态。

自动计算时长的模式目前要求直线恒速**参考航迹**。10 m/s 是控制目标，不保证真值在整段始终恰好为 10 m/s。无物理运动扰动时，质量检查使用配置中的速度容差（默认 ±10%）寻找连续有效航段；开启物理运动扰动时，速度范围仍报告，但不因偏离名义速度而直接判失败。两种情况都要检查真实前进距离是否覆盖目标长度，裁剪窗两端也必须落在真值与导航共有采样时刻上。

## 3. 参数怎么调

### 飞行与采样

| 界面字段 | 含义与建议 |
|---|---|
| 目标有效航线长度 (m) | 想从最终真值中取得的连续前进距离；默认 1000 m。修改后重新计算总时长。 |
| 名义速度 (m/s) | 直线参考航迹和飞行时长计算使用的目标速度；默认 10 m/s。 |
| 额外飞行裕量 (s) | 加在 `长度÷速度` 之外的时间；默认 10 s。用于给目标航段两侧留余地，不能代替实际有效航段检查。 |
| 时长计算方式 | `route_length` 自动计算；`fixed` 使用“固定模式航迹时长”。 |
| 有效航段速度容差比例 | 默认 `0.1` 表示无物理扰动时名义速度的 ±10%；受物理扰动时只报告波动。 |
| APC 名义高度、名义偏航 | 定义参考轨迹与天线相位中心的几何基准。高度以 APC 为准。 |
| 积分 / SAR / 导航 / 公共扰动频率 | 控制真值积分及各输出时间网格；默认导航为 100 Hz。频率组合必须满足配置校验，增大频率会增加计算和文件大小。 |
| 质心 → APC 杆臂 | 按机体 FRD 的“前 +X、右 +Y、下 +Z”分别输入，单位 m；默认 `(0, 0.1, 0.2)` m，是仿真安装值，不是实机标定结果。 |

内部运动坐标采用 NED/FRD；对外 SAR 位置与速度采用 X 前、Y 右、Z 上。修改杆臂会改变 APC 真值和导航 APC 估计，但不会直接改变机体质心的真实运动。

### 导航估计误差

当前默认开启“X1指标参考 · GNSS/INS误差状态模型”。加速度计输入是FRD比力，陀螺仪输入是FRD角速度；误差经过统一传播与GNSS校正，生成位置、速度和姿态估计。

- 加速度计慢变偏置：三轴标准差，m/s²；默认各0.000686。
- 加速度计白噪声：速度随机游走，m/s/√h；默认各0.03。
- 陀螺仪慢变偏置：三轴标准差，deg/h；默认各3。
- 陀螺仪白噪声：角度随机游走，deg/√h；默认各0.2。
- 偏置相关时间：默认100 s，属于未标定工程假设。
- GNSS：可设置开关、更新频率（默认5 Hz），及NED三轴位置/速度观测标准差。这里的NED第三轴向下，与SAR向上不同。
- 双天线航向辅助：可关闭，默认观测标准差0.08°。关闭GNSS时该辅助也停止。
- 初始化误差和导航随机种子：可分别修改；相同参数和种子应复现同一模型输出。

随机游走不是每个100 Hz采样点的白噪声标准差，不使用此前80%/20%的输出误差拆分。要关闭某类IMU误差，将相应三轴慢变偏置和随机游走同时设0；初始化误差和GNSS观测噪声仍会影响结果。GNSS关闭后速度和位置会累积漂移。超过5°姿态误差时模型会报错，提示线性近似失效。

参数依据、局限及坐标约定见 [GNSS/INS模型说明](../../docs/gnss_ins_model.md)。关闭整个新模型仅用于兼容旧YAML统计模型，旧参数不会被自动换算成IMU参数。更改导航参数不影响物理真值。结果页的PVA曲线展示融合结果；IMU融合诊断图展示残余偏置和预测位置标准差。

#### GNSS 与初始化参数默认值

| 参数 | 当前默认 | 操作含义 |
|---|---|---|
| 启用 GNSS/INS | 开启 | 正常使用时保持开启；取消勾选会回到旧统计模型，并不代表关闭所有导航误差。 |
| GNSS 校正 | 开启，5 Hz | 每0.2秒更新一次；关闭后整个输出航段自由传播，同时停止航向辅助。当前界面不支持设定中途失锁时间窗。 |
| GNSS 位置观测 σ · NED | [0.007778, 0.007778, 0.016] m | 假定1 km基线RTK固定解；水平二维指标分配到两个分量。它是输入观测误差，不是最终导航位置误差。 |
| GNSS 速度观测 σ · NED | [0.021213, 0.021213, 0.03] m/s | 水平按二维合量解释；垂直值为工程假设。 |
| 双天线航向辅助 | 开启，0.08° | 参考2 m天线基线指标；该基线不同于质心至APC杆臂，也不同于双航次基线。只取消此项可观察缺少直接航向辅助的影响。 |
| 初始位置 / 速度 σ | 0.02 m / 0.03 m/s | 各轴初始不确定性；模型从输出航段起点初始化，不模拟开机对准过程。 |
| 初始横滚俯仰 / 航向 σ | 0.018° / 0.084° | 对准后工程初值；不是持续叠加到每一个采样点的姿态噪声。 |
| 导航随机种子 | 0 | 与基础种子、航次种子一起决定导航随机实现。 |

标准差不是误差上限。例如0.000686 m/s²约对应70 μg，是当前模型的残余加计偏置尺度；不能填写70或70e-6来代替该值。陀螺3 deg/h也不是3 deg/s。随机游走参数由程序换算为连续噪声强度并离散积分，改变输出采样率时不要自行乘除100。

手册给出的零偏不稳定性并不严格等于OU标准差，目前作近似使用；100秒相关时间及观测协方差解释也属于工程假设。参数改大通常会增加传播误差，但融合结果还受GNSS更新、运动状态和滤波协方差影响，不保证输出RMS与输入参数成正比。

#### 常用对比实验

1. **生成默认结果。** 保持GNSS/INS、GNSS和航向辅助三个开关开启；另存配置后运行双航次，作为对照。
2. **增加IMU误差。** 固定基础、航次及导航种子，将加计或陀螺偏置、随机游走分别调整，避免同时改动所有参数。对比PVA误差曲线及残余偏置图。传感器误差会通过传播耦合到其他输出轴。
3. **降低GNSS观测质量。** 保持IMU参数与种子，将GNSS位置或速度观测σ调大，再次运行。这里同时改变滤波所采用的观测噪声协方差，不是向最终结果额外添加一层噪声。
4. **比较有无GNSS。** 只取消“GNSS校正”勾选，保留“启用GNSS/INS”。建议先用固定模式短航段试验，再增加时长；若姿态误差超过5°，需缩短航段或调整参数使模型回到适用范围，不能放宽有效性检查。
5. **检查可复现性。** 用同一个已保存YAML重复运行，比较相同时间戳的输出；用不同导航种子观察统计变化。只修改导航参数时，物理真值应保持一致。

保存前给配置起英文文件名，例如`gnss_reference.yaml`、`imu_noise_high.yaml`、`gnss_disabled.yaml`。上位机保存完整参数，运行任务也会保存独立快照；原来已保存的旧配置不会自动升级，建议以当前默认配置重新建立实验。

### 运动扰动

当前默认六轴均为`small`，并在幅度框显示数值：A的X/Y/Z各0.05 m，B的Roll/Pitch各0.5°、Yaw为1°。指令层切换等级会填入对应候选幅度，也可手填覆盖。独立随机种子只改变该通道随机曲线的实现，不改变等级和幅度；它与基础种子、航次种子及通道标识共同决定随机流，留空按0参与组合。`constant`过程不使用随机曲线。

“运动扰动”中的 A 组是平移 X/Y/Z，B 组是 Roll/Pitch/Yaw。每轴可设置开关、强度等级、幅度、过程类型 `ou` 或 `constant`、起止时刻、过渡时长和随机种子；顶部还有 OU 快慢相关时间及方差权重。`ou` 的“幅度”是标准差，`constant` 的“幅度”是常量。

“注入层”决定幅度单位：默认 A 平移 X/Y/Z 均为 `command` 位置目标扰动，三轴单位都是 m，中等等级 OU 输入标准差各为 0.15 m；B 姿态指令层单位为 deg。飞控追踪被扰动的位置目标，扰动生效时不保证回到未扰动的名义位置，但位置目标不会因 X 速度噪声积分而持续漂移。可通过“加载配置”选择 [三轴外力配置](../../configs/three_axis_force_6n.yaml)，改用三轴 FRD 外力，各轴 OU 标准差 6 N，名义位置目标保持不变。外力和位置目标的数值不能直接比较，均未实飞标定。单独切换某轴注入层会清空旧幅度，必须按新单位重新填写；如需保持三轴同机制，应核对全部三轴。旧配置若把 X 指令层写为 m/s，需手动重新设定为 m 和合适的位置幅度，不能直接沿用旧数字。若只想改变导航测量质量而保持真实航迹，使用“导航估计误差”，不要打开物理运动扰动。

### 执行与资源

“基础随机种子”“航次种子”控制可复现的随机实现。双航次需至少两个互不相同的航次种子。改变随机种子后，即使误差强度相同，具体轨迹也可能不同；比较参数影响时应记录或固定种子。

“基础随机种子”旁的“随机”按钮会生成并填入一个0至4294967295之间的整数；不会自动开始仿真。可继续手动修改或另存配置，运行时该数值会写入参数快照。运行中的任务继续使用启动时的种子，新值用于下一次任务；点击此按钮不会修改航次种子或导航独立种子。

“航次种子”旁也有“随机”按钮：按当前逗号分隔的种子数量，生成同等数量且互不重复的32位非负整数；输入为空时使用默认数量。默认两个航次就生成两个种子。按钮不会改变基础种子、导航独立种子或自动开始运行，生成的值同样随配置和任务快照保存。

“并行进程上限”填 `0` 为自动；内存使用比例、保留内存和每进程数值库线程限制资源使用。“刷新硬件”显示 CPU、可用内存及 GPU/空闲显存。当前动力学计算仍为 CPU 后端；检测到 GPU 不表示积分已经在 GPU 上运行。

## 4. 两个运行按钮的区别

| 按钮 | 用途 | 结果状态 |
|---|---|---|
| 运行仿真 | 快速试验当前参数，可选单航次或双航次；生成 MAT/CSV、图表、离线报告和有效航段检查。 | 成功时显示“仿真完成”，报告中的完整科研/接口验收标为未执行。 |
| 完整验收 | 固定双航次，运行已有本地完整链路，包括自动化测试、长 OU 统计、数值收敛和可选 MATLAB 接口检查。 | 全部通过才显示“完整验收通过”；跳过必需检查可能是“部分完成”。 |

“完整验收”的 MATLAB 选项：`auto` 自动检测，`required` 要求其通过，`skip` 跳过。外部 SAR 工程的 PRF/脉冲数等参数不会由上位机自动修改；更改输出时长或采样频率后，如需 MATLAB 接口验收，应先确认双方配置兼容。外部 ArduPilot/PX4 平台的部署和飞行不由这两个按钮自动执行。

点击“停止当前任务”只终止本上位机启动的任务树，已经生成的部分文件会保留。运行开始时会保存独立参数快照；任务运行期间编辑界面只影响**下一次**运行。建议先用“另存配置”把实验参数保存为完整 YAML，再运行并保留任务目录中的 `input_config.yaml`。

## 5. 查看和提取结果

每次上位机任务单独保存在 `main/gui_outputs/simulate_<时间戳>/` 或 `main/gui_outputs/acceptance_<时间戳>/`，不会覆盖历史任务。常用文件如下：

```text
<任务目录>/
  input_config.yaml             # 启动时的完整参数快照
  worker.log                    # 运行日志
  session.json                  # 窗口记录的最终状态
  result.json                   # 子进程返回的结果路径和状态（成功时）
  index.html                    # 仿真模式离线报告；验收模式位于 artifacts/acceptance_*/index.html
  artifacts/run_*/              # 仿真模式原始数据目录
  artifacts/acceptance_*/       # 完整验收目录，原始数据在其 validate_* 子目录
```

原始数据目录中的 `motion_truth_pass1.csv` 是高频运动真值，`motion_navigation_pass1.csv` 是对应导航输出；`navigation_pass1.csv` 与 `navigation_truth_pass1.csv` 用于上位机逐帧位姿对照。双航次时有相应的 `pass2` 文件。目录还包含 MAT、`metadata.json`、`validation.json`、图表及报告使用的数据。用这些文件进行后续 SAR 仿真时，应以本次 `input_config.yaml`、报告中的裁剪时间窗和文件里的时间戳为准，不按标称频率自行猜测起止行号。

“结果查看”可选择图表、切换航次、在质心与 APC 间切换三维航迹，并显示真值与导航估计。按住左键拖动三维图旋转，右键拖动缩放；勾选“真实比例”可看实际几何比例，或点击“重置视角”。“导航位姿逐帧对照”用时间滑块查看位置、速度、姿态、四元数和 APC 的同一导航采样时刻数据。

“打开离线报告”会在浏览器打开当前报告；“打开结果文件夹”打开当前原始数据目录。“载入已有结果”时，应选择**包含** `navigation_pass1.csv` 和 `navigation_truth_pass1.csv` 的原始数据目录，而非上层任务目录。对于已有外部同钟航迹，“外部同钟航迹应用杆臂”另生成 APC 派生目录，保留原始文件；它不是杆臂实测标定。

### 新导航模型的图表和字段

| 产出 | 查看内容 |
|---|---|
| 三维航迹 | 拖动查看完整真值与导航估计航迹；离线报告将三维轨迹放在关键产出可视化的第一项。 |
| 导航位置 / 速度 / 姿态对比 | 最终融合PVA与真值的差异。速度仍是需要输出的导航结果，参数输入已改为IMU误差。 |
| `navigation_pose_errors.png` | 三轴位置、速度及机体系小姿态旋转向量误差；最后一组不等于直接相减的欧拉角。 |
| `imu_gnss_diagnostics.png` | 加速度计残余偏置、陀螺残余偏置、预测位置标准差；后者是滤波器预测的不确定性，不等于当前实际误差。 |
| 导航MAT中的 `ins_error_state` | 每行15维：[NED位置3维、NED速度3维、NED小姿态角3维、FRD加计残余偏置3维、FRD陀螺残余偏置3维]；内部姿态用rad、陀螺偏置用rad/s。 |
| `ins_error_std` / `gnss_update` | 对应15维状态的预测标准差，以及该导航采样点是否执行GNSS更新。 |

GNSS更新可能让估计误差在更新时刻跳变，不能据此判断物理真值突然跳动。当前模拟的是局部线性化误差状态传播，尚不导出原始带噪IMU测量日志；带`truth_`前缀的加速度和角速度依旧是物理真值。MAT中的模型标识应为`Local NED 15-state linearized GNSS/INS error-state Kalman simulation`；旧结果不会被追溯重算。

### 人工验收顺序

先查看任务最终状态与日志，再确认航线覆盖、采样频率和时间戳；随后拖动三维轨迹，检查PVA误差及融合诊断图。完整验收还应查看自动化测试、数值收敛、MATLAB阶段和必需图表是否通过。模型程序检查通过不等于已经满足北云实机性能；当前理想化GNSS没有多径和系统偏差，不能把较小的模拟RMS直接当成设备实测精度。

## 6. 常见情况

| 现象 | 核对方式 |
|---|---|
| 双击没有打开窗口 | 检查 `.venv` 是否已由 `scripts/setup.ps1` 创建；也可从项目根目录运行 `uv run --no-sync python main/internal/control_panel.py` 查看错误。 |
| 底部提示参数无效 | 点击“检查参数”查看具体字段；优先核对频率整除、时间网格、正的速度和独立航次种子。不要靠放宽约束掩盖问题。 |
| 目标 1000 m 但有效航段未通过 | 查看离线报告的实际前进距离、速度范围和裁剪窗；检查扰动、控制能力、飞行裕量及是否选择了直线参考。原始输出会保留，目标长度并不保证物理仿真必然达标。 |
| 结果页状态为“部分完成” | 查看 `acceptance.json` 和日志中的未执行阶段；常见原因是 MATLAB 被跳过或相关外部工程不可用。 |
| 加载历史结果时报目录错误 | 进入 `artifacts/run_*/` 或 `artifacts/acceptance_*/validate_*/`，选到包含导航 CSV 的那一级。 |
| 需要复现实验 | 保留任务目录中的 `input_config.yaml`、随机种子、`metadata.json` 和日志；重新运行可能生成新任务目录，不会覆盖旧数据。 |
| 新参数在窗口里没出现，仍显示速度误差输入 | 关闭旧窗口，从当前项目的`main/open_control_panel.cmd`重新打开；确认没有启动另一个历史项目。 |
| 关闭GNSS/INS后仍有误差 | 该开关关闭会回到旧统计模型；正常对比GNSS失锁应关闭“GNSS校正”，并保持GNSS/INS开启。 |
| 提示姿态误差超过5° | 当前小角度线性化模型已超出适用范围；核对陀螺单位、GNSS开关和航段时长。 |
| 提示GNSS频率不能高于导航频率 | GNSS观测只能在导航时间网格更新；将GNSS频率设为不高于导航频率的值，默认5/100 Hz。 |
| 离线报告打不开 | 先确认任务已结束、当前结果目录和报告路径有效；可进入任务目录直接双击`index.html`。完整验收报告通常在`artifacts/acceptance_*/`中。 |

更详细的实现和验收边界见 [上位机技术说明](CONTROL_PANEL.md) 与 [运动模块说明](../../docs/motion_module.md)。

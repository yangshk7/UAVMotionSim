# Desktop Control Panel

双击 `main/open_control_panel.cmd` 启动桌面上位机。也可在工程根目录运行：

```powershell
uv run --no-sync python main/internal/control_panel.py
```

使用已安装的 Tkinter / Pillow，无新增 GUI 依赖。`main/tools/open_control_panel.ps1` 提供 PowerShell 启动方式；图形界面与数值任务采用独立进程，运行时窗口可以继续响应。

## 可控制参数

- 导航位置/速度/姿态估计误差：独立开关、三轴慢变标准差、三轴白噪声标准差、相关时间、随机种子。位置支持等级预设与自定义三轴值。单轴标准差为零表示该误差分量关闭。
- 飞行与采样：速度、APC 高度、偏航、预稳定/输出航迹时长、积分/SAR/导航/公共扰动频率、波束安装和杆臂、质量、电机时常数、旋翼推力上限。航迹可设为 100 s 等较长时段，后续在 SAR 程序中裁剪。
- 杆臂在“飞行与采样 → 天线相位中心安装 · 仿真杆臂”分别输入前/右/下三个 FRD 分量；默认 `(0,0.1,0.2) m` 来自两份已有仿真规范。它是仿真安装值，含义、坐标变换和验证见[杆臂说明](../../docs/lever_arm_simulation.md)。
- 上位机默认加载 `motion_config.yaml`，按 `route_length` 自动计算总时长；输入目标航线长度、速度和额外裕量（默认 10 s）。无物理扰动时，速度 ±10% 是连续匀速航段的检查门槛；开启物理扰动时，速度仅报告实际范围，不以名义速度带否决仿真。两种情况均要求实际连续前进距离覆盖目标长度，裁剪窗首末点必须落在真值与 100 Hz 导航共有时刻。若飞行时间不足以覆盖目标长度，原始数据仍保存并标记不达标。原 `config.yaml` 保留固定时长验收基准，可通过“加载配置”切换。
- A/B 运动扰动：各轴开关、指令/动力学注入、候选等级、显式幅度、OU/constant、起止时间、过渡时长、种子；全局 OU 快慢时间和权重。
- 运行资源：航次种子、名义基线、进程上限、可用内存比例、内存保留和数值库线程。硬件信息显示 CPU、可用 RAM、GPU/空闲显存；当前仍为 CPU 计算后端。

所有数值经原 Pydantic 配置校验，不通过降低约束接受非法参数。未显示的完整惯量、飞控增益、航点等配置字段会保留。加载配置不会改动源文件；“另存配置”保存完整 YAML。

**标准差不是最大误差。** 要关闭某轴误差，需同时将该轴慢变和白噪声标准差设为零。姿态误差为 FRD 小旋转向量，进入 SO(3) 后生成姿态角与四元数。改变导航估计不会改变真实运动。切换扰动注入层会清空旧幅度，要求重新填写与单位一致的数值，避免把 m/deg 直接当作 N/N*m。

## 运行流程

1. 在“参数配置”中调整关键参数，点击“检查参数”；底部显示预期采样数量。
2. 点击“运行仿真”默认生成一段航迹，也可选择两段；每段同时导出原生积分频率真值与 100 Hz 导航估计，另保留原有 SAR/MAT 文件、图表和离线报告。本模式不宣称完成测试/统计/收敛/MATLAB 验收。
3. 最终配置点击“完整验收”，调用既有 main/internal/run.py 的全部已实现链路，固定双航次。MATLAB 可选 auto / required / skip；未执行项会保留 partial 状态。
4. “运行监控”显示实时日志。启动后立即保存独立参数快照；期间编辑仅用于下一次任务。停止只终止本上位机启动的任务树，已生成文件会保留。
5. “结果查看”提供中文图表预览、可拖动的三维航迹和导航位姿时间滑块。三维图可切换航次、质心/APC、真实/独立坐标比例；显示导航估计与真值。按住左键拖动旋转，右键拖动缩放。也可以打开离线验收页、结果目录或加载历史数据。可用 `uv run --no-sync python main/internal/control_panel.py --result-dir <数据目录>` 直接载入历史结果并打开三维图。
6. 如需给外部飞控已对时的机体航迹生成 APC，在“结果查看”点击“外部同钟航迹应用杆臂”，选择 `clock_sync` 或 `clock_sync_final` 目录。程序用当前上位机输入的杆臂新建派生目录，分别保存真值与导航 APC；原始文件保留。

每次任务保存在 `main/gui_outputs/<mode>_<Shanghai_timestamp>/`，包括 input_config.yaml、worker.log、session.json、result.json 和 artifacts。手动保存配置默认进入 main/gui_configs；启动异常进入 main/gui_logs。上述目录均不覆盖实验原件。

“运行仿真”可调整频率与时长；“完整验收”的 MATLAB 运动接口仍需与外部 SAR 的 PRF/脉冲数等参数一致。上位机不改动外部雷达参数，不提供串口/遥测飞行器控制，也不把检测到 GPU 误写为已启用 GPU 积分。

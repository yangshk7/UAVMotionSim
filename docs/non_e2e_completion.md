# 非端到端运动模块交付与验证

> 历史记录/原始设计：以下参数、测试数量、路径和结论仅对应文中版本，不是最终版现状。最终版统一以 [v1.1.0发布说明](FINAL_RELEASE.md) 和其引用的最终验收记录为准。原始结果未追溯修改。

本记录只涵盖高频仿真真值、100 Hz 导航估计、参数控制、航段裁剪、扰动响应和外部数据就绪审计；不执行 SAR 回波或成像。

## 可直接使用的运动数据

- 上位机默认读取 `main/motion_config.yaml`：输入目标有效航线长度 `L`、目标速度 `v` 和可修改的额外裕量 `M`，输出时长向上对齐公共采样网格，`T=L/v+M`。默认 `M=10 s`、速度容差为 `±10%`。
- RotorPy 六旋翼输出原生积分频率真值和 100 Hz 导航估计。两路共享精确时间原点；质心位置/速度、NED/FRD 姿态和 SAR APC 位置分别标明。运动扰动、导航位置/速度/姿态估计误差与随机种子均可由上位机调整。
- 质量检查逐个原生真值点检查速度模长，并要求沿航前进距离达到 `L`。裁剪首末点必须同时属于高频真值与 100 Hz 导航网格。`crop_motion_segment` 同步裁剪两路并将新时间原点置零，不改原始数据；不合格航段不会靠删点、平滑或篡改速度变成合格。

实际运行的无扰动 `L=1000 m`、`v=10 m/s`、`M=10 s` 示例，原始完整输出为 110 s，位于 `results/module_1000m/run_20261102_104157_168588/`。重算的公共网格裁剪窗为 **5.00–105.00 s**，沿 X 前进 **1000.000000000045 m**，真值速度约为 **9.99999999994–10.00000000003 m/s**，满足 9–11 m/s 门槛。独立裁剪包在其子目录 `cropped_1000m/`，含 **320001 个 3200 Hz 真值点**和 **10001 个 100 Hz 导航点**；重新读入及契约校验已通过。`route_quality_common_grid.json` 是新算法的复核结果，先前 `validation.json` 和 `route_quality_recheck.json` 保留了当时的选择规则，未被覆盖。

## 单因素可控性试验

入口：`uv run --no-sync python scripts/motion_sensitivity.py --output results/motion_sensitivity/<new_run_name>`。本次使用 RotorPy 基准，输出段 8 s，3 个配对随机种子 `101/102/103`，仅改变 SAR Y 向**指令** OU 扰动标准差。全部配置、种子、逐次指标和中文图保存在 `results/motion_sensitivity/paired_8s/`。

管道计算采用原生真值 APC 位置：`r_i=sqrt(y_APC,i²+(z_APC,i-z_target)²)`，`D95=2×r_i` 的最近秩 95% 分位。它是采样点相对名义中心线的圆柱直径，不是连续时间安全界限。

| 横向指令 OU 标准差 | D95 均值 | 三次重复标准差 |
|---:|---:|---:|
| 0 m | 约 0 m | 0 m |
| 0.15 m | 0.735 m | 0.202 m |
| 0.30 m | 1.760 m | 0.861 m |

这是该短时、该控制器和候选参数下的仿真响应；随机波形与控制闭环使单次结果不一定单调，不能据此宣称输入标准差等于实际管道直径，更不能推断 12 kg 实机精度。上位机调整导航误差只影响估计量，不影响真值。

## 外部平台接入审计

入口：`uv run --no-sync python deployment/audit_motion_sources.py --source px4|sitl --directory <run_dir> --output <new_json>`；审计只读原始 CSV，拒绝覆盖已有报告。

| 采集段 | 真值记录 | 导航记录 | 目前是否可写成同步 `MotionSegment` |
|---|---|---|---|
| PX4/Gazebo | 20496 个独立仿真时戳，1 ms 间隔，约 1000 Hz | 2050 点 / 20.496 s，平均约 99.97 Hz；间隔有 8/16 ms 变化 | 否 |
| ArduPilot SITL | 6833 个真值消息，依导航航段时长估算约 333 Hz；无独立仿真时戳，接收消息有突发聚集 | 1026 点 / 20.5 s，50 Hz | 否 |

本节表格是先前**仅按消息流审计**的状态，报告保存在各运行目录的 `motion_source_audit.json`。随后复用了 PX4 ULog 与 SITL DataFlash，找到了各自物理真值和导航的共同仿真时钟，形成严格对时的机体轨迹数据；证据、原生与插值频率、最新 `motion_source_audit_aligned.json` 见[外部时钟对齐报告](external_clock_alignment.md)。两平台仍缺少本机体 CG→SAR APC 标定杆臂与导航共同原点；目标机型无实飞日志，动力学与导航误差参数仍是可配置工程初值。

现阶段面向后续 SAR 的主交付仍可使用本项目 **3200 Hz RotorPy 物理真值 + 100 Hz 合成导航估计**，并在每次运行查看速度、连续长度及裁剪报告。现已另交付同钟的 PX4/Gazebo 和 SITL 机体真值与飞控导航 CSV；前者原生真值位置/姿态 1000 Hz，后者原生位置/速度约 400 Hz、真值姿态更低频。两者用于 SAR APC 前仍需杆臂与外参标定。

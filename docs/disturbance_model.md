# A/B/E 扰动与几何解耦

A 指令层：X 为 SAR 航向速度指令扰动（m/s），名义 X 位置目标保持不变，位置环会校正累积位置偏差；其导数作为加速度前馈。Y/Z 为 SAR 参考位置偏移（m），微分为速度和加速度。B 指令层：Roll/Pitch/Yaw 为 FRD 姿态右乘偏置（YAML 度，计算 rad），体轴角速度由姿态参数化的导数换算。旧结果若使用了 X 扰动积分为参考位置的实现，仍保留原始数据，不按新模型重解释。

动力学层 A 为 FRD 外力 N、B 为 FRD 外力矩 N m。必须显式给出各自幅度和单位，不能把位置/角度预设换名当作 N/N m。轴开关独立；默认全部关闭，等级 Medium。

双尺度过程：

\[
d=\sigma(\sqrt{0.7}u_s+\sqrt{0.3}u_f),\quad
u_{k+1}=a u_k+\sqrt{1-a^2}\xi_k,\quad a=e^{-\Delta t/\tau}.
\]

慢/快相关时间初值 2.5/0.35 s。初值从单位稳态分布抽样；使用 `expm1` 避免小步长下创新方差消减误差。各通道、快慢过程、航次与导航使用独立 SeedSequence。更改某个开关不会让其他通道随机流移位。

预生成网格默认 3200 Hz；用于积分收敛时固定为共同的 6400 Hz。动力学只读连续 C2 样条输入，不在 RK4 子步抽噪声。指令层额外经过三阶 1 Hz Butterworth 低通并乘五次开关窗，避免不可微 OU 的高频位置导数进入飞控。YAML 的 amplitude 表示低通前候选 OU 标准差；低通、开关、限幅和飞控均会改变最终运动幅度，不能把候选值理解成实际飞行误差保证。

导航 E 在 100 Hz 生成慢变位置偏差（默认相关时间 8 s）和测量白噪声。用户后续授权增加速度/姿态误差：速度慢变标准差 [0.02,0.02,0.04] m/s、相关时间 3 s；FRD 小旋转向量标准差 [0.05°,0.05°,0.10°]、相关时间 5 s。新增白噪声默认零，可配置。姿态在 SO(3) 上右乘误差，不直接叠加欧拉角。三类误差彼此独立且不影响真实动力学。800 Hz 导航位置/速度采用线性重采样、姿态采用 SLERP，不重新抽取噪声。导航式字段来源见数据接口。

SAR 几何解耦在 `geometry.translation/attitude` 中独立选择 ideal/actual。选出的平移和姿态分别构造连续样条，再微分得到实验速度、加速度、角速度和角加速度；保存在 `sar_geometry`，标记 `geometry_decoupled`、`physical_truth=false`。这些量不覆盖、也不反馈物理真值。

三级候选值保存在 `disturbances/presets.py`，配置可覆盖。导航误差、扰动和飞控参数尚未经实测校准。

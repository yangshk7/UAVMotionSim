# 12 kg Hex-X 实测标定准备

> 版本口径：最终版参数、功能边界与验收结论统一以 [v1.0.0发布说明](FINAL_RELEASE.md) 为准。本文带日期的运行数字是对应历史实验记录，不代表最终版重新测得的结果。

截至 2026-11-01，本机没有目标 12 kg Hex-X 的实飞日志、台架推力数据或传感器标定数据。外部仿真航线仅检验模型和软件闭环，不能用其自身产生的“真值”反推并宣称模型已获实测标定。

已核对的公开资料见 [公开飞行数据](public_flight_data.md)。[UAV-FD](https://zenodo.org/records/7648996) 是其他六旋翼的 ArduPilot 实飞与电机转速数据；现已下载两段无故障记录，完成校验、机载 GPS/EKF 速度一致性统计及六路 PWM→RPM 拟合与独立航次检查。[MUN-FRL](https://mun-frl-vil-dataset.readthedocs.io/en/latest/) 是 DJI M600 的同步 IMU 与 RTK/PPK 轨迹，适合验证独立真值对照，但其单段完整 ROS bag 为数十 GB，本阶段未下载。两者均不能提供本机型的质量、惯量、电机参数或导航误差标准差；没有改动 `configs/` 的工程初值。

第三项公开实飞导航误差评估方法已在带 Leica 独立位置真值的 NTU VIRAL `eee_01` 航段完成，见[对照报告](public_navigation_validation.md)。该结果属于其他无人机的 FAST-LIO2 算法，不构成本项目 Hex-X 实机导航精度。MUN-FRL 的 RTK/PPK 特定流程尚未运行。

## 需要采集的数据

| 目标参数 | 必需的独立数据 | 基本辨识条件 |
|---|---|---|
| 质量、质心、惯量 | 装机称重、重心测量、摆法或 CAD 加实测核验 | 载荷与电池状态固定，给出不确定度 |
| 单桨推力/扭矩曲线 | 同款电机、桨、ESC、电池的台架转速、电流、推力、反扭矩 | 覆盖怠速、悬停和高推力区，不以 PWM 直接代替转速 |
| 电机时间常数 | 台架阶跃命令与同步转速 | 上升和下降分开估计，排除 ESC 限速段 |
| IMU 噪声与偏置 | 原始 IMU 静止长记录、温度、采样率 | 标注单位与滤波设置，区分白噪声和慢变偏置 |
| 导航位置、速度、姿态误差 | 飞控估计与独立 RTK/PPK 或运动捕捉、姿态参考 | 对齐时钟和坐标系、外参；先估延迟，再计算残差 |
| 风扰模型 | 同步风速风向与飞行记录 | 至少有不同方向/速度的往返航段，避免把控制误差误认为风 |

## 标定与验收顺序

1. 原始日志只读归档，记录机型、载荷、固件、传感器、时间基准、坐标系、单位和校验哈希。
2. 对时并转换坐标，估计杆臂、固定偏移与处理延迟；保留每对样本的时间差，剔除超出同步容差的配对。
3. 用台架数据拟合推力、扭矩和电机响应；用独立质量/惯量数据约束动力学。训练航段拟合，留出不同航段验证，报告残差和置信区间。
4. 在静止与飞行数据分别估计 IMU 偏置和噪声；导航误差须与独立参考轨迹比较。位置、速度和姿态通道各自报告，不把仿真偏差写成实测误差。
5. 生成新的版本化参数文件，保存拟合脚本、输入哈希、随机种子、分段规则与验证图；只有在独立航段指标通过后，才考虑替换工程初值。

目前第 1 步缺少目标机型实测输入，因此本机型参数辨识尚未开始。已完成的仿真真值对照可用于检查对时、坐标变换和误差报告流程，但不构成实机校准。

# 运动模块阶段验收记录（2026-11-02）

本次只验收一段高频仿真真值、对应的 100 Hz 导航位姿、可配置扰动和杆臂、长度规划、数据契约与离线查看页面。不把本次参数仿真误写为完整双航次科研验收、SAR 回波成像或实机精度标定。

结果数据是本机生成产物，不随 GitHub 源码发布。两份通过的上位机结果仍位于本机 `main/gui_outputs/`；其他历史运行目录原样移入项目旁的 `UAVMotionSim_Archive_20261102/`，该目录的 `archive_manifest.json` 记录原路径与归档路径。下文保留原运行时相对路径，复算时可根据归档记录定位。

## 验收口径

- 无物理扰动：在原生真值采样点检查目标速度的可配置容差带（本次为 10 m/s ±10%），要求存在覆盖目标长度的连续匀速航段。
- 开启物理扰动：速度容差带只报告观测统计，不据此否决真实的速度波动。要求真值有限、位置/速度/姿态运动学一致、四元数单位模、SAR 时间网格准确、航迹实际连续前进距离覆盖目标长度，且裁剪窗首末点是高频真值与 100 Hz 导航的共同采样时刻。
- 扰动配置和随机种子随数据保存。同配置与同种子的重复运行应可复现。本次未建立随机扰动输出幅度的统计预测区间；输入标准差不能直接当作实际速度或管道的容差。
- `T = L/v + M` 是规划时长，不保证任意扰动下必然覆盖 `L`。不足时保留原始数据并明确标记不达标。

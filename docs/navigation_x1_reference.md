# 北云 X1 参数依据（最终版）

当前默认为15状态线性化GNSS/INS误差模型，完整指标、换算及工程假设以[模型说明](gnss_ins_model.md)为准。原先独立PVA误差80%/20%拆分已停用，只在旧配置兼容模式中保留，不是最终版默认。

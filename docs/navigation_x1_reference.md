## 必要的建模假设

- 手册未说明水平 RMS 是二维合量还是单轴，本项目明确按二维合量解释，假定X/Y等方差，满足 `sqrt(σx²+σy²)=水平RMS`。这是仿真假设，不是厂家定义。
- 在零均值假设下将 RMS 当作标准差。现有误差模型为零均值稳态OU加白噪声，不能据此还原实际设备的固定偏置、频谱或GNSS/IMU融合算法。
- 手册未给出慢变与白噪声分解。默认将给定幅度全部分配给慢变项，三类白噪声均设为0；否则叠加会增大总RMS。位置、速度、姿态相关时间仍为8/3/5 s，属于可配置工程初值。
- 手册给出欧拉角精度，代码以SO(3)机体小旋转向量施加误差；近水平、小误差时可近似对应横滚、俯仰、方位。大姿态运动时不能保证各欧拉角RMS仍等于表中数值。
- 表3-1的INS最大输出为125 Hz；仿真导航输出仍按任务要求为100 Hz。这里设置的是组合导航解算结果的统计误差，不是给真值加IMU原始传感器噪声。
- 有限航段的实测RMS会因随机种子、相关时间和长度变化，不强制缩放单次结果来凑手册数值。未模拟RTK浮点、失锁、10秒中断后的漂移或后处理改善；也未完成目标实机标定。

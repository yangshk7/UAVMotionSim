# 六旋翼动力学与飞控

> 版本口径：最终版参数、功能边界与验收结论统一以 [v1.0.0发布说明](FINAL_RELEASE.md) 为准。本文带日期的运行数字是对应历史实验记录，不代表最终版重新测得的结果。

状态为 `[p_N(3),v_N(3),q_NB(4),omega_B(3),Omega(6)]`，共 19 维，全部采用 SI。12 kg、0.55 m 机臂和惯量 diag(0.55,0.60,1.00) kg m² 为规范推荐初值，可在 YAML 修改。

旋翼编号角度 `alpha_i=30°+60°i`，推力 `T_i=kf Omega_i²` 沿 FRD -Z。`r_i×[0,0,-T_i]` 给出滚转/俯仰力矩，因此分配矩阵第 i 列为 `[1,-y_i,x_i,s_i km/kf]`，`s=[+1,-1,+1,-1,+1,-1]`。总推力 117.72 N 时，悬停每旋翼 19.62 N；单旋翼限幅 0–42 N。

分配先使用预计算加权伪逆。若违反旋翼限制，求解带盒约束的加权最小二乘，并将残差回传给控制器冻结积分，避免通过截断伪造可行力矩。

\[
\dot p_N=v_N,\quad \dot v_N=ge_3+R_{NB}(F_r+F_D+F_e)/m,
\]
\[
\dot\omega_B=J^{-1}(\tau_r+\tau_e-\omega_B\times J\omega_B),\quad
\dot q=\tfrac12 q\otimes[0,\omega_B],\quad
\dot\Omega=(\Omega_{cmd}-\Omega)/\tau_m.
\]

电机时间常数 0.1 s；默认无阻力/无风，允许单独开启确定性体轴二次阻力 `-.5 rho CdA |v_B| v_B`。无地面接触、旋翼故障和完整电磁电机模型。

固定步长 RK4 默认 3200 Hz，四元数每整步归一化。外力在起点/半步/终点读取同一预生成连续样条，电机命令在控制更新间零阶保持。四个环的频率为 20/50/200/200 Hz，通过整数步索引更新。

位置 P 产生速度，速度 PI 加加速度前馈；加速度经过速度/水平加速度/垂直加速度/倾角约束。期望姿态由推力方向和偏航构造。姿态误差用 SO(3) 对数，角速度 PI 产生含陀螺耦合补偿的力矩。

增益首先检查含 0.1 s 执行器的近悬停小角度闭环极点，再用悬停、巡航、速度偏差、高度恢复、加减速、升高、横移与三个姿态恢复试验验证。极点分析仅适用于小角度、未饱和条件，不能替代非线性仿真，也不是实机飞控认证。

航迹支持恒速、分段平滑速度、航点自然三次样条和带速度的 Hermite 时间序列。样条导数直接给出速度/加速度；区间外按端点速度延拓，避免预稳定期间外推发散。参考速度和加速度超限会明确报错。

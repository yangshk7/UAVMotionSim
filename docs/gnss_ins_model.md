# X1 指标参考 GNSS/INS 误差模型

> 版本口径：最终版参数、功能边界与验收结论统一以 [v1.0.0发布说明](FINAL_RELEASE.md) 为准。本文带日期的运行数字是对应历史实验记录，不代表最终版重新测得的结果。

当前标准配置开启 `disturbances.imu_gnss.enabled`。上位机配置加速度计与陀螺仪误差、GNSS观测及航向辅助，PVA输出误差由统一模型传播和校正。旧的独立位置/速度/姿态统计配置仅供历史实验兼容，在新模式下不参与最终输出；此前80%/20%输出方差拆分也不再使用。

## 手册依据与工程假设

依据用户提供的北云X1手册UG014 V1.1（2024-04-24）。表3-3（PDF第10页）给出X1-5加计零偏不稳定性70 μg、速度随机游走0.03 m/s/√h，陀螺零偏不稳定性3 deg/h、角度随机游走0.2 deg/√h。将70 μg以标准重力9.80665换算并保留6位小数，得到0.000686 m/s²。传感器三轴采用相同指标。

手册的零偏不稳定性不是OU稳态标准差的严格等价量；这里将它近似作为对准后的残余偏置OU标准差，相关时间100 s是工程假设。表中的启动零偏重复性5 mg和0.1 deg/s没有再次叠加到已对准残余状态上；本模型不模拟启动标定过程。不得宣称已完成真实传感器Allan方差辨识。

表3-1的GNSS更新频率5 Hz被用于观测更新。默认假设RTK固定解、基线1 km：水平0.01 m+1 ppm得到0.011 m二维RMS，按X/Y等方差分配；垂直0.015 m+1 ppm得到0.016 m。测速0.03 m/s按水平二维RMS分配，垂直暂取0.03 m/s。手册未给出这套观测协方差的完整定义，此处均属显式建模解释。位置与速度观测独立白噪声，未模拟多径、RTK浮点、基站误差和观测相关性。

默认双天线航向观测σ=0.08 deg，参考手册2 m基线指标；假定完成安装对准，在每次GNSS时刻提供小角度航向观测，并非实现真实双天线载波观测。可关闭航向辅助。初始化位置0.02 m、速度0.03 m/s、横滚/俯仰0.018 deg、航向0.084 deg为对准后工程假设，均可配置。表3-2的组合导航PVA精度仅作为对照，绝不再次叠加到滤波输出或用于强制缩放结果。

## 数学模型及适用范围

状态为估计减真值的15维误差 `[δp_N, δv_N, δθ_N, δb_a_B, δb_g_B]`，内部采用NED/FRD；加计偏置单位m/s²，陀螺偏置内部rad/s。局部固定导航系，忽略地球自转、曲率和重力梯度。

在线性小角度近似下：`δp'=δv`，`δv'=-[f_N]×δθ+R_NB δb_a+n_a`，`δθ'=R_NB δb_g+n_g`。其中`f_N=a_N-g_N`为比力、`R_NB`是机体到导航系旋转；两个偏置服从一阶Gauss-Markov过程。使用已知物理真值作为线性化参考轨迹来模拟误差传播，不是从原始IMU日志运行完整非线性机械编排，也不复现北云固件。

随机游走系数除以60，换算到每√秒连续白噪声强度。连续过程噪声协方差通过三点Gauss积分离散，包含位置、速度、姿态的交叉项；因此不将随机游走数值误作100 Hz逐点标准差。状态转移使用三阶展开，采样步长需远小于偏置相关时间和运动变化时间。

GNSS观测位置和速度，航向辅助观测导航系小偏航误差。Kalman更新同时校正PVA和偏置残差，协方差采用Joseph形式。输出姿态为`Exp(δθ_N) R_true`，再转为接口约定的机体系右乘旋转向量。任一时刻姿态误差超过5°则拒绝输出，避免超出线性模型范围后继续宣称有效。

导航输出仍为100 Hz；5 Hz校正可能使误差在更新时刻发生跳变，这是离散滤波更新的结果。重采样到SAR频率不增加导航信息。关闭GNSS时同时关闭该来源的航向辅助；误差自由传播，不能继续套用GNSS未中断精度。

## 输出与验收

原有导航PVA及真值字段保持物理含义。MAT导航记录新增`ins_error_state`、`ins_error_std`和`gnss_update`，可核对传播状态、预测标准差与更新时刻；加速度和角速度的`truth_`字段继续标识物理真值，不冒充IMU原始测量。当前不导出原始带噪IMU日志。

验收包括恒定加计偏差解析关系`δv=bt`、`δp=bt²/2`，零误差传播、独立随机种子复现、GNSS更新计数及多种子有/无GNSS漂移比较，并运行原有完整动力学、接口和报告流程。验收通过仅证明这些检查通过，不能等同于达到X1实机精度；单次误差RMS及长期统计需按实际产出报告。

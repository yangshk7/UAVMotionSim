# 可选高加速度研究配置

2026-11-07。基于项目 `configs/hex_x_12kg.yaml` 生成，仅修改 `profile_validation.json` 列出的控制上限。

- `hex_x12_high_accel_20261107.yaml`：水平加速度 6 m/s²、垂向加速度 4 m/s²。
- `hex_x12_high_dynamic_20261107.yaml`：上述设置，加姿态角速度指令上限 3 rad/s、roll/pitch 力矩上限 24 N·m；yaw 力矩上限仍为 2 N·m。

两份配置均保留倾角上限 25°、单电机最大推力 42 N 和有界推力分配。加速度与倾角约束共同起作用，不能保证所有垂向指令下均达到水平 6 m/s²。

在项目根目录选择配置，例如：

```powershell
.\.venv\Scripts\python.exe -m uavsim.cli run --config research_profiles/hex_x12_high_accel_20261107.yaml --passes 1
```

第二份用于研究更强动态下的控制限幅影响。它没有重新整定控制增益，不能据此保证任意输入均稳定或从不触限；电机物理边界仍参与模拟。

配置使用原基准的其他参数；本轮论文实验的 1.2 倍增益、4 秒孔径及宽频指令由研究脚本另行设置，加载本文件不会自动复现论文实验。原始配置默认关闭的扰动开关也按原值保存，需要按原工作流程启用所需扰动。
